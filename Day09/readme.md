# 🤖 Day 9 — Smart Student Agent (Memory + Multi-Tool)

Day 9 of my **100 Days of Agentic AI** journey.

## 📚 Topics Covered

- Persistent Conversation Memory
- Long-Term Notes Memory
- Native Function Calling
- Multi-Tool AI Agent
- Context-Aware Conversations
- JSON Storage

## 🛠️ Project

Built a **Smart Student AI Assistant** that combines conversation memory, personal notes, and Python tools into one stateful agent.

### Features

- 💬 Remembers previous conversations
- 📝 Save personal notes
- 📖 Show saved notes
- 🗑 Delete notes
- ➕ Calculator
- 🎓 CGPA Calculator
- 📊 Percentage & Grade Calculator
- 📅 Attendance Calculator
- 🔐 Password Generator

## Memory System

- `chat_history.json` → Stores conversation
- `notes.json` → Stores long-term personal notes

## Key Learning

A true Agentic AI combines **Reasoning + Memory + Tools + Persistent Storage** to behave like a personal assistant rather than a simple chatbot.
