## 🛠️ Project

Built an **AI Interview Coach** that:

- Accepts target job role
- Takes interview questions
- Evaluates candidate answers
- Gives score out of 10
- Suggests improvements
- Generates a better sample answer
- Supports multiple interview rounds until the user exits

## 💻 Tech Stack

- Python
- Google Gemini API
- python-dotenv

This project demonstrates how LLMs can be guided using well-structured prompts to simulate real technical interviews.
